A short text written to relax the AI judge: a jar of river water left on a kitchen sill, settling from storm to clear over one evening. `main.ts` (Node 22, standard library only) writes it to `/output/entry.txt`, the same bytes every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
